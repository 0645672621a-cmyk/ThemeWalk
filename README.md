# ThemeWalk｜主题漫游

**给旅途一个线索，拍下原本会错过的美。**

[打开 ThemeWalk 网页](https://0645672621a-cmyk.github.io/travel-photo-themes/)

Colorwalk 是带着一种颜色去散步、寻找并拍摄它。ThemeWalk 从这个玩法出发，把颜色扩展成六类观察主题：抽一张卡，带着它走进街道、风景与人群，发现旅途中值得留住的画面。

这是一个轻量的旅行拍照提示工具。它给你拍摄线索，不规定照片必须长什么样；同一张卡，在不同地方、不同人的眼里，可以有完全不同的答案。

## 六种观察主题

| 主题 | 卡片 | 可以寻找什么 |
| --- | ---: | --- |
| 颜色 | 14 张 | 红、橙、黄、绿、深蓝、浅蓝、紫、黑、白、粉、棕、金、银、灰 |
| 画面图案 | 8 张 | 网格、波点、条纹、波浪、斑驳、重复、无序、纯色 |
| 旅途中的人 | 4 张 | 情侣、朋友、亲子、单人 |
| 取景方式 | 8 张 | 抬头、低头、景框、倒影、光影、细节、远景、抓拍 |
| 形状 | 8 张 | 圆形、方形、三角形、菱形、拱形、心形、星形、螺旋 |
| 数字 | 8 张 | 旅途中出现的数字 1～8 |

共 **50 张卡**。每张卡都有一个极简图形作为提示。

## 怎么玩

1. 选择今天想观察的主题，点击「开始抽取」。
2. 带着抽到的卡边走边看，找到属于你的画面并拍下来。比如抽到「波浪」，可以拍水纹、屋檐的曲线，也可以拍一段蜿蜒的路。
3. 想继续探索时点击「继续抽取」；也可以切换主题，给同一段旅程换一种观察方式。

同一主题内，卡片抽完前不会重复；六个主题分别记录进度。点击「重新开始」只会清空当前主题的记录。抽取记录保存在当前浏览器中，清除浏览器网站数据后会消失。

## 使用与部署

项目是一个独立的静态网页，入口为 [`index.html`](./index.html)。手机或电脑浏览器都可以打开；部署到静态网站后，可以直接分享网页链接。无需安装依赖或配置服务端。

使用 GitHub Pages 时，把 `index.html` 和本 `README.md` 放在仓库根目录，并将 Pages 的发布来源设为对应分支的根目录。README 用于介绍玩法，实际网页由 `index.html` 提供。
